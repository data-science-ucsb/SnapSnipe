# Dataset card

Put photos in `data/raw/<category>/` — one folder per category in `config.py`, named exactly the same.

```
data/raw/
├── pizza/    (40+ photos)
├── salad/
└── burrito/
```

Tip: upload on GitHub with **Add file → Upload files**. Phone photos are fine; try to keep each under ~2 MB.
